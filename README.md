# lab

Maps, data experiments and side projects by Lukas Posolda. Each project is a folder, served by GitHub Pages at `https://lukasposolda-qwertz.github.io/lab/<folder>/`.

| Folder | Project |
|---|---|
| `kaffeklassikern/` | Kaffeklassikern, a collection game for Sweden's roasteries (built site; source kept elsewhere) |
| `coffee-roasters-of-sweden/` | Map of every coffee roaster in Sweden in OpenStreetMap |
| `cafes-of-stockholm/` | Stockholm's cafés with an opening-hours slider |
| `pendlingskartan/` | Commuting between Sweden's municipalities, 2004–2024 |
| `stationskarta/` | Sweden's railway stations, in use, closed and planned |
| `fastighetskarta/` | Unofficial map of Jernhusen's published property list |
| `otter/` | Four Claude models draw the same otter |

New experiments start as a new folder here.

Two GitHub Actions in `.github/workflows/` rebuild map data from OpenStreetMap every Monday (cafés 03:00 UTC, roasters 03:30 UTC). Each can also be started by hand from the Actions tab with "Run workflow".

Each folder keeps its own licence and notices.
